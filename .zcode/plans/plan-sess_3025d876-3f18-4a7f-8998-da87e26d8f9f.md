# 智枢星项目架构重写方案

## 一、目标与原则

将散装脚本集合重写为成熟可维护的 Python 包，**严格保留现有业务逻辑与数值行为**，补齐功能断点，完成仓库治理。原则：逻辑平移不重设计（合成数据数值、checkpoint 命名、API 契约、前端交互全部保持）；单一来源（重复代码归一）；路径与密钥零硬编码；每个环节有测试。

## 二、目标架构


## 三、"现有逻辑"保持清单（重写验收基准）

- 合成数据数值特征逐一保留：拥堵热力图 12区/17时段/三峰/分层缓解率；换乘时间 520→398 等降幅与噪声结构；安检排队 backup_share sigmoid 分流规则与双种子；微调指标收敛曲线
- MADDPG：超参默认值、reward npy 命名 `MADDPG_env_{env}_number_{}_seed_{}.npy`、checkpoint 命名 `{algo}_actor_number_{}_step_{}k_agent_{}.pth`、训练循环顺序（deepcopy 动作、逐 agent 训练、噪声衰减）
- 3 个 PassengerGroup 演示场景（A口→地铁/主安检、B口→高铁/备用安检@t=8、A口→公交@t=14）统一进 configs/scenarios.json，demo/webapp/PWA 共用
- Web 12 个既有端点路径与响应结构不变；UnityTemplate C# 不动
- 移动端页面结构、localStorage schema（routeHistory/zsx_user/zsx_prefs/aiConfig）不变

## 四、实施步骤

**第1步 仓库治理（前向）**：新增 .gitignore；基线提交当前未提交改动；`git rm --cached` 移除 node_modules(187M)、16个.pyc、ml-agents 双镜像(438M,含坏gitlink)、50MB mp4/11MB zip/AR.gif，磁盘上迁移 ml-agents 至 `third_party/`（gitignore）；删除无引用的 package.json/pnpm-lock/file-viewer3。**提醒：泄漏的 SiliconFlow/高德密钥须到平台作废重发（历史中仍可见，本次不做破坏性清史）。**

**第2步 包骨架**：pyproject（setuptools, requires-python>=3.10, 入口 `zhishuxing=zhishuxing.cli:main`）；config.py 集中路径与密钥（SILICONFLOW_API_KEY/AMAP_KEY 等环境变量读取）；git mv 迁移模块至新结构。

**第3步 core**：navigation.py 平移（A*、必经点串接）；scenarios.py（PassengerGroup+场景加载）；flow.py（generate_dynamic_flow 平移）；simulation.py（rl_bridge 中的网格仿真，与 RL 解耦为"策略协议"注入）；animation.py（animate_transfer_env 平移）。

**第4步 analysis 统一（去重核心）**：字体设置 6份→1份；moving_average 2→1；CSV 读写 3+4处→io_utils；**两套发散的模拟微调指标合并为一个生成器**（可配置参数）；5 类报告改为可 import 函数+薄 CLI；修复已发现 bug：安检图南北区标签互换、find_latest_npy 误选非奖励 npy、fine/plot_finetune_metrics 无 Agg+plt.show() 挂起、输出路径全部改锚定 workspace 而非 CWD。

**第5步 rl 包**：maddpg.py+matd3.py 合并为 agents.py（TD3 三技巧作为开关，`--algorithm MATD3` 真正生效，修复其 save_model 缺 makedirs）；runner.py 路径走 config；runtime.py 平移 rl_bridge；buffer.py 增加 current_size<batch_size 的明确报错信息。

**第6步 llm + planning**：MockLLMAdapter 平移；新增 SiliconFlowOpenAIAdapter（OpenAI 兼容接口，env key，无 key 时自动降级 Mock 并在响应中标注）；amap.py 迁移 jiaohu.py 真实管线（OD提取LLM+正则兜底、geocode、transit、polyline 解析、城市推断），**偏好参数真正传入规划 strategy**（现状是假收集）；webapp 新增 `POST /api/plan`（引擎参数：`amap` 真实路线 / `hub` 内部 A*+RL 仿真）。

**第7步 webapp 重构**：service.py 合并 system+web-service 职责；blueprint 分组（navigation/rl/llm/dashboard/plan）；既有 12 端点平移；新增 `GET /mobile` 直接服务 PWA（同源免 CORS）；run_existing_features 加每脚本 timeout(120s)+结构化结果+补跑 queue/efficiency 两脚本；smoke_test 迁移为 tests/test_api.py。

**第8步 移动端 PWA**：planRoute 的 setTimeout mock 替换为 fetch `/api/plan`（离线/失败回退 mock 并标注"演示数据"）；修复 sw.js（VR1.png→VR.png）并真正调用 `navigator.serviceWorker.register`；theme 色统一；修复硬编码路线话术改为接口返回。

**第9步 测试与文档**：pytest 七件套（A*正确性/合成数据种子确定性与数值范围/权重加载回环/仿真到达率/API全端点/polyline解析+OD正则/CLI冒烟）；README 重写（架构图、快速开始、API 表）；docs/architecture.md。

**第10步 性能优化（按 code-optimization 技能）**：基线测量 animation 的 step()（44人×1000步）与 500 人扩展性 → 迭代1：社会力/密度 O(n²) 循环 numpy 向量化 → 迭代2：视距网格分区(空间哈希)邻居检索 → 正确性校验（同 seed 轨迹统计一致）→ 报告写入 `code_optimization/report.md`（基线/v1/v2、加速比、内存、验证结果）。

## 五、验收

全部 pytest 通过；`zhishuxing demo/analyze all/simulate/serve` 四链路跑通且产物落位 data/；webapp 与移动端 PWA 手动可用；`git status` 干净无大文件；README 图链有效。

## 六、不做的事

不改 Unity C# 与 MADDPG 数值行为；不做 git 历史重写（密钥清史需你单独确认）；不引入前端构建链（保留原生 JS）；Streamlit 依赖不再使用（原型归档 legacy/）。
